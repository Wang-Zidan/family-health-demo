# 家庭健康 AI 管家 · 演示前端部署指南

## 文件说明
- `index.html` — 单文件演示前端，无需构建，直接打开即可
- 对接 Matrix API（Tuwunel），通过 Higress Gateway 端口通信

## 部署方式（Cloud Studio）

### 方式 1：注入到 Controller 容器的 Nginx（推荐 ✅）

这样前端和 Matrix API **同源**，没有跨域问题：

```bash
# 1. 复制 HTML 到 Controller 容器内
docker cp /workspace/family-health-demo/demo/index.html agentteams-controller:/opt/element-web/demo.html

# 2. 在容器内修改 nginx 配置，添加 demo 路由
docker exec agentteams-controller bash -c '
echo "location /demo { alias /opt/element-web/; index demo.html; }" >> /etc/nginx/conf.d/element-web.conf
nginx -s reload
'

# 3. 访问（通过 Cloud Studio 的 18088 预览端口）
# http://<cloud-studio-preview-url>/demo
```

### 方式 2：独立端口服务（简单但可能有跨域）

```bash
# 在 Cloud Studio 新终端启动静态服务器
cd /workspace/family-health-demo && python3 -m http.server 18090

# 然后在浏览器打开 Cloud Studio 的 18090 端口预览
# 注意：需要在页面中把 Matrix 地址改为 Cloud Studio 提供的外部地址
```

## 使用流程（录屏演示用）

1. 打开页面 → 输入 Admin 凭据登录
2. 左侧看到所有房间列表（Manager DM + 各 Worker 房间）
3. 点击房间进入对话
4. 底部有**快捷按钮**，一键发送典型任务：
   - 📋 解读体检报告
   - 🥗 饮食建议
   - 💊 用药检查
   - 🏥 就医准备
   - 📈 趋势分析
5. 观察 Worker 回复（带打字动画）
6. 录屏！

## 页面特性

| 特性 | 说明 |
|------|------|
| 登录页 | 渐变背景 + 品牌Logo + 自动填充默认值 |
| 侧边栏 | 房间列表 + 团队成员标签 |
| 聊天区 | 消息气泡 + 发送者标识 + 时间戳 |

## 自定义配置

如果 Matrix 服务器地址不是默认的 `http://127.0.0.1:18080`：
- 登录页可以手动修改地址输入框
- 或直接改 HTML 第 285 行的 value 默认值
