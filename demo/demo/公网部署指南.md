# 家庭健康 AI 管家 · 公网演示部署指南

## 架构目标
评委通过**公网链接**直接访问演示，无需任何本地环境。

## Cloud Studio 公网预览机制

预览 URL 格式：
```
https://${X_IDE_SPACE_KEY}--${PORT}.${X_IDE_SPACE_REGION}.${X_IDE_SPACE_HOST}
```

在 Cloud Studio 终端中可获取变量：
```bash
echo $X_IDE_SPACE_KEY
echo $X_IDE_SPACE_REGION
echo $X_IDE_SPACE_HOST
```

## 部署方案：同源公网（推荐 ✅）

### 原理
前端页面和 Matrix API 部署在同一域名下（Controller 容器的 nginx），避免跨域（CORS）问题。

```
评委浏览器
  → https://xxx--18088.region.cloudstudio.club/demo  (前端 HTML)
  → https://xxx--18088.region.cloudstudio.club/_matrix  (Matrix API，同源)
  → Higress Gateway (18080) → Tuwunel → Manager/Workers → MCP (18089)
```

### 步骤

```bash
# 1. 复制前端到 Controller 容器（Element Web 的静态文件目录）
docker cp /workspace/family-health-demo/demo/index.html agentteams-controller:/opt/element-web/demo.html

# 2. 修改 nginx 配置：添加 /demo 和 /_matrix 反向代理
docker exec agentteams-controller bash -c 'cat >> /etc/nginx/conf.d/element-web.conf << EOF

location /demo {
    alias /opt/element-web/;
    index demo.html;
}

location /_matrix/ {
    proxy_pass http://127.0.0.1:8090/;  # Higress/Matrix 内部地址（需确认）
    proxy_set_header Host \$host;
    proxy_set_header X-Real-IP \$remote_addr;
}
EOF
nginx -t && nginx -s reload
'

# 3. 开启 18088 端口公网访问
# 在 Cloud Studio 界面的「端口」面板，开启 18088 的外部访问
# 系统会生成公网 URL

# 4. 评委访问：https://生成的公网URL/demo
```

> **注意**：第 2 步中的 Matrix 内部地址需要根据实际环境确认（可能是 18080 容器端口或 Higress 内部服务名）。先用 `docker exec agentteams-controller curl -s http://127.0.0.1:8090/_matrix/client/versions` 测试。

## 备选方案：独立前端 + 公网 Matrix

如果同源部署复杂，可以：

1. 前端用独立端口（如 18090）`python3 -m http.server 18090 --bind 0.0.0.0`
2. 开启 18090 和 18080 两个端口的公网访问
3. 前端 Matrix 地址填：`https://xxx--18080.region.cloudstudio.club`
4. 若遇 CORS 错误，在 Higress 配置中添加 CORS 响应头

## 注意事项

1. **保持 Cloud Studio 工作空间运行**：公网访问依赖工作空间持续运行
2. **端口必须监听 0.0.0.0**：MCP 服务器已满足，前端 http.server 需加 `--bind 0.0.0.0`
3. **免费额度**：注意 Cloud Studio 免费额度到期时间，比赛期间不要欠费停机
4. **提交前测试**：用手机热点（非同一网络）打开链接验证评委视角
